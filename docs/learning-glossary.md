# CreditPilot Learning Glossary

Short definitions you'll see a lot.

- **Repository (repo)** — a project folder tracked by Git
- **Commit** — a saved snapshot of your code with a message
- **Monorepo** — one repo containing frontend + backend together
- **Server** — a program that listens for requests and responds
- **Request / Response** — you ask the API something; it answers with data or an error
- **JSON** — a common text format for sending data (`{"balance": 120}`)
- **Status code** — number meaning of a response (`200` ok, `201` created, `401` not logged in, `404` not found)
- **Dependency** — a package your code needs (FastAPI, SQLAlchemy, etc.)
- **Environment variable** — a setting outside code (database URL, secret key)
- **Hash** — one-way scramble of a password for safe storage
- **ORM** — write Python classes that map to database tables
- **Migration** — a versioned change to database structure (we'll add later with Alembic)
